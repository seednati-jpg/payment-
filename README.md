# דרישת תשלום ודוחות נסיעות

אפליקציית PWA (React + Vite + jsPDF) להפקת דרישות תשלום ל-PDF ושיתוף מהיר בנייד.
כל הנתונים נשמרים בדפדפן (localStorage) — אין שרת ואין צורך במפתחות API.

## הרצה מקומית
    npm install
    npm run dev        # http://localhost:3000

## בנייה
    npm run build      # פלט בתיקיית dist
    npm run preview

## פריסה
Vercel: Framework = Vite, Build = `npm run build`, Output = `dist`.
